# NexusChat — план разработки (D:\nc\nexuschat)

База: ранняя версия 0.1.0 (Tauri + React + Rust). Дорожная карта до уровня Discord.
Один этап = одна версия. После этапа: `cargo clippy --all-targets`, `cargo test`, `pnpm build`,
поднять версию, коммит, обновить bundle/zip.

## Текущее состояние (что уже есть)
- Вход/регистрация, JWT-сессии (access 15 мин + refresh 30 дней).
- Серверы, каналы и категории; базовые роли `owner/admin/member` + пользовательские роли с битовыми правами и переопределениями на канал.
- Сообщения (создать/править/удалить), пагинация.
- Личные сообщения 1:1, файлы (S3/MinIO), присутствие, непрочитанные, приглашения.
- События между экземплярами (LISTEN/NOTIFY), WebSocket.

## Инструменты
- Установлено: Rust 1.100 (MSVC + Build Tools), pnpm 12.18, git, docker.
- Node.js на ПК сейчас отсутствует: клиент проверяется через `docker build --target client`.
- Проверено: `cargo check` сервера проходит на базе.

## Правила работы над этапом
1. Сервер: миграции + обработчики + тест.
2. Клиент: экран + состояния (загрузка/пусто/ошибка).
3. Проверки: `cargo clippy --all-targets`, `cargo test`, `client: pnpm build`.
4. Поднять версию, коммит.
5. Обновить bundle/zip для переноса (после согласования).

## Технические заметки
- Проект теперь под git; каждый этап — отдельный коммит; в конце этапа `git bundle` для переноса.
- Секреты (`JWT_SECRET`, пароли) не класть в git/архивы.
- Не ослаблять безопасность ради удобства.
